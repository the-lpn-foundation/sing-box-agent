# Support

## Bugs and feature requests

Open a [GitHub Issue](https://github.com/the-lpn-foundation/sing-box-agent/issues).
Please include the agent version, a minimal reproduction (config snippet,
`curl` command, expected vs actual output), and relevant log lines —
**redact tokens and secrets**. See
[CONTRIBUTING.md](./CONTRIBUTING.md) for the expected issue format.

## Security vulnerabilities

Do **not** open a public issue for security problems. Follow the private
disclosure process in [SECURITY.md](./SECURITY.md).

## Documentation

Setup, deployment, and API documentation lives in the
[`docs/`](./docs) directory:

- [`docs/integration-guide.md`](./docs/integration-guide.md) — API contract
  and request signing.
- [`docs/deployment.md`](./docs/deployment.md) — systemd and Docker
  deployment.
- [`docs/spec.md`](./docs/spec.md) — detailed specification.

## Questions and discussions

For usage questions and ideas, use GitHub
[Discussions](https://github.com/the-lpn-foundation/sing-box-agent/discussions) if
they are enabled for this repository; otherwise ask in an issue with the
`question` label.
